# Маппинг полей товаров: МойСклад API → БД (таблица pbi_products)
# Формат: поле_api | поле_бд | тип_данных [ | трансформация ]
#
# Трансформации (необязательный 4-й столбец):
#   /N   — разделить значение на N (например /100 для цен в копейках)
#   *N   — умножить значение на N
#
# Типы данных:
#   STRING(N)      — строка длиной N символов
#   TEXT           — длинный текст (NVARCHAR(MAX))
#   INTEGER        — целое число
#   BIGINT         — большое целое число
#   DECIMAL(P,S)   — число с фиксированной точкой
#   FLOAT          — число с плавающей точкой
#   BOOLEAN        — логическое (BIT)
#   DATE           — дата и время
#   JSON           — объект/массив сериализуется в JSON-строку
#
# Способы указания поля API:
#   name                    — простое поле
#   meta.href               — вложенное поле через точку
#   attribute(UUID)         — значение доп. поля по ID атрибута из attributes[]
#   attribute(UUID).name    — имя доп. поля (вместо value)
#   mappedAttributes        — все доп. поля по скриншоту в один JSON (см. utils/mappedAttributesRules.js)
#
# Для meta.href и *.meta.href автоматически извлекается UUID из URL
#
# packs.N.* — поле N-й упаковки (с нуля), например packs.0.id — первая упаковка
#
# salePrice("имя типа цены") — value из элемента salePrices[], где priceType.name совпадает с именем;
#   ненужные типы цен просто не указываются в маппинге. Значение в копейках — используйте | /100
#
